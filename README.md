# Task 4 - Version-Controlled DevOps Project with Git

## Objective
Manage a DevOps project using Git best practices.

## Tools Used
- Git
- GitHub

## Branching Strategy
- main: Stable production branch
- dev: Development branch
- feature: New feature development

## Tasks
- Initialize Git repository.
- Create and manage branches.
- Make commits with meaningful messages.
- Merge feature changes using Pull Requests.
- Use .gitignore to exclude unnecessary files.
- Create Git tags for versioning.

## Outcome
Learn version control workflows and Git best practices.

## Git Workflow Completed

- Created main, dev, and feature branches.
- Added a sample feature in feature branch.
- Created Pull Request #1 from feature to dev.
- Successfully merged the Pull Request into dev.
- Added .gitignore to exclude unnecessary files.
- Created and pushed Git tag v1.0.

## Commit History
